# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users
Commerçants et PME (restaurants, bars, glaciers, artisans) qui cherchent un
prestataire web pour présenter leur activité et, selon le cas, prendre des
réservations ou des paiements en ligne. Ils jugent vite, souvent sur mobile,
et ne sont pas techniciens.

## Product Purpose
Site vitrine d'un développeur fullstack freelance qui vend des sites et
applications web clé en main. Succès : le visiteur demande un devis
(CTA « Demander un devis »).

## Positioning
Un seul interlocuteur qui conçoit, code sur mesure, héberge et sécurise.
Quatre différences confirmées : clé en main + sécurité VPS, paiement et
réservation intégrés, un seul interlocuteur, code sur mesure (pas de template).

## Operating Context
Offre en 3 packs : Vitrine, Vitrine +, Maintenance. Processus en 4 étapes :
échange, maquette validée avant tout code, développement, mise en ligne.
Contact via formulaire (email envoyé par le backend).

## Capabilities and Constraints
- Site multilingue : FR, EN, IT, ES (redesign en cours, non commité).
- Panneau admin pour gérer projets, compétences et messages.
- Stack : React 19 + Vite, Node/Express, Prisma/PostgreSQL, hébergé sur VPS.
- Contrainte : tout nouveau texte existe au minimum en FR et EN.
- Aucun prix publié sur les packs dans le code actuel (décision non confirmée).

## Brand Commitments
- Le nom de famille ne doit pas apparaître sur le site.
- Ton direct, tutoiement non utilisé ; vouvoiement dans les textes actuels.

## Evidence on Hand
Projets réels (seed backend) : Il Subito (commande et paiement en ligne),
Site Vitrine Restaurant & Bar, Worksocial, Gelateria Aurora, QCM Quiz.
Parcours : Simplon, Wild Code School, autodidacte.
Absent du code : témoignages clients, chiffres de performance, nombre de
clients. Ne pas en inventer.

## Product Principles
1. Parler le langage du commerçant, pas du développeur.
2. Prouver par des projets réels, jamais par des chiffres inventés.
3. Rassurer sur la sécurité et la maintenance sans jargon.
4. Un chemin court vers le devis depuis chaque page.

## Accessibility & Inclusion
Aucune exigence spécifique confirmée. Site multilingue ; usage mobile attendu.
